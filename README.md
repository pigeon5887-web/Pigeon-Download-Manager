# Pigeon Download Manager V1.2.0（测试版）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Go Version](https://img.shields.io/badge/Go-1.21%2B-blue.svg)](https://golang.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)]()

一个基于 Go 语言开发的、模块化且可扩展的**多网盘命令行下载管家**。

> 🚧 **测试版说明**：本版本为功能测试版。123 云盘文件下载暂不可用（官方接口限制，详见已知限制），更多网盘支持持续开发中。

## 通道支持矩阵

| 网盘 | 目录浏览 | 文件下载 | 提取码 | 说明 |
|------|:---:|:---:|:---:|------|
| 蓝奏云 | ✓ 任意深度 | ✓ | ✓ | 新版 `/s/` 与老版 `/b/` 目录格式均支持，自动翻页 |
| 夸克网盘 | ✓ 任意深度 | ✓ | ✓ | 直连官方接口，免登录匿名下载 |
| UC 网盘 | ✓ 任意深度 | ✓ | ✓ | 同夸克架构，`drive.uc.cn` / `fast.uc.cn` 链接均支持 |
| 百度网盘 | ✓ | ✓ | — | 浏览器扫码登录，凭据加密保存 |
| 123 云盘 | ✓ 任意深度 | ✗ | ✓ | 列表/导航可用，下载受官方版本校验限制（见已知限制） |

## 核心特性

*   **多网盘一站式**：蓝奏云、夸克、UC 的目录解析基于各网盘**官方 Web 端协议的逆向分析**实现（解析思路参考 [netdisk-fast-download](https://github.com/qaiu/netdisk-fast-download) 项目；蓝奏云单文件直链解析仍由其本地服务承担），支持免登录匿名下载与任意深度目录导航；123 云盘、百度网盘经成熟引擎接入。
*   **百度式命令交互**：网盘链接模式与百度模式统一使用 `ls` / `cd <序号>` / `cd ..` / `download 0|1,3,5` / `u` / `q` 命令组，`download 0` 全选、`1,3,5` 多选，裸数字输入同样兼容。
*   **16 线程下载加速**：aria2 多连接调度（`split=16`），实测可线性突破单连接限速。
*   **多任务进度视监**：多文件下载逐行原地刷新进度，完结任务定格显示，全程不打断。
*   **无感登录与安全加密**：百度网盘支持多浏览器（Edge / Chrome / Brave）唤起扫码，静默提取 HttpOnly Cookie，凭证采用 **AES-256-GCM** 加密存储。
*   **123 云盘账号一键配置**：首次解析 123 云盘分享时引导输入账号密码，自动写入解析服务配置并热重启，全程本地保存。
*   **下载路径可配置**：主菜单随时更换下载目录，自动校验可写性；程序位于受保护目录（如 `C:\Windows`）时配置自动降级保存到 `%AppData%`。
*   **双擎自动调度与自愈**：后台自动静默拉起 `aria2c` 与解析服务，意外退出自动复活，退出程序时自动清理端口，即用即走。
*   **高扩展性架构**：内置 `Parser` 接口与网盘类型自动路由，按域名自动分发到对应解析器并匹配下载头。

## 快速开始

1. 前往本仓库的 **Releases** 页面，下载最新的测试版安装包 `Pigeon-v1.2.0-Setup.exe`。
2. 双击运行安装程序，按照指引完成安装（建议使用默认路径）。
3. 安装完成后，双击桌面快捷方式或开始菜单中的 `Pigeon Download Manager` 运行。
4. **注意**：首次运行如遇 Windows Defender 或杀毒软件拦截，请点击“更多信息” -> “仍要运行”（个人开发者无代码签名，属正常现象）。

## 使用指南

程序启动后，会自动在后台拉起下载引擎和解析服务，随后弹出主菜单：

### 1. 解析蓝奏云等链接
- 粘贴蓝奏云分享链接（提取码可直接写在链接里，如 `...?pwd=xxxx`，也可后续按提示输入）。
- 目录分享支持 `ls` / `cd <序号>` / `cd ..` 逐层浏览，`download 0` 全部下载、`download 1,3,5` 多选。
- 文件默认保存在主程序所在目录的 `downloads` 文件夹内（可通过主菜单 `5` 更改）。

### 3. 解析123云盘链接
- 首次使用会引导配置 123 云盘账号（凭据仅保存在本机解析服务配置中）。
- 目录分享支持逐层浏览与多选，文件下载当前受官方接口校验限制，详见[已知限制](#已知限制)。

### 4. 解析夸克/UC链接
- 粘贴夸克 / UC 分享链接（`drive.uc.cn` 与 `fast.uc.cn` 均可，提取码写法同上）。
- 支持任意深度目录浏览与多选下载，免登录。

### 2. 进入百度网盘交互模式
- **首次使用**：程序会弹出干净的浏览器（可选择 Edge/Chrome/Brave），请**扫码登录**。登录成功后凭证**加密保存**为 `baidu_cookie.pigeon`，下次无需再扫码。
- 指令：`ls` / `cd <序号>` / `cd "目录名"` / `download <序号1,序号2>` / `download <序号> -p <线程数>` / `quit` 退出。

### 5. 设置下载路径
- 查看并更换下载目录，自动校验可写性并持久保存。

### 通用操作
- 各交互层级中：`q` 返回上一级，`Ctrl+C` 返回主菜单（下载任务不受影响，继续后台进行）。
- 主菜单输入 `q` 退出，自动清理后台服务。

## 已知限制

- **123 云盘文件下载**：官方对网页/API 下载通道启用了客户端版本校验（接口返回错误码 5066），当前版本可正常浏览与定位文件，但发起下载会被官方拒绝，需使用 123 云盘官方客户端。解析服务更新后本工具将自动恢复该能力。
- **移动云盘**：新门户为 SPA 架构且接口带签名校验，适配开发中。
- 部分网盘对免登录下载有速度限制，本工具已默认启用 aria2 多线程（16 连接）以改善体验。

## 从源码编译

确保你的电脑已安装 Go 1.21 或更高版本。

    git clone https://github.com/pigeon5887-web/pigeon-download-manager.git
    cd pigeon-download-manager
    go build -o pigeon_disk_download.exe .
